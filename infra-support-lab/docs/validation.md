# Проверка перед публикацией

Локальная проверка 11 ноября 2026 года: Windows, Python 3.12.14.

- `python -m unittest discover -s tests -v`: 24 теста прошли.
- `python -m infra_support demo`: healthy = OK, stale-backup incident = FAIL; ожидаемый код завершения 0.
- Проверены локальный TCP-сервис, разрешение localhost, восстановление ZIP с побайтным сравнением, отсутствующая/повреждённая/просроченная копия, пороги диска, конфигурация, экранирование HTML и коды завершения.
- PowerShell-скрипт прошёл синтаксический разбор и выполнен под Windows. Выгрузка состояния машины не включена в репозиторий.
- sqlcmd проверен с подменой внешнего процесса: успешный SELECT 1, отсутствие инструмента, ошибка, таймаут, способ передачи пароля. Настоящий SQL Server не использовался.
- Bash-скрипт и выполнение под Ubuntu локально не проверялись: Bash/Ubuntu в доступной среде отсутствуют. Для дальнейшей проверки добавлен workflow Windows/Ubuntu; облачный workflow ещё не запускался.

Первый запуск тестов в ограниченной песочнице не имел доступа к её временному каталогу и локальным TCP-соединениям. Успешный прогон выполнен с доступным временным каталогом и разрешённым loopback. Для обычного запуска проекта специальных разрешений администратора не требуется; права на конкретные диагностические команды зависят от политики машины.
